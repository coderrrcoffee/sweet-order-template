# Sweet Order — универсальный шаблон сайта-витрины

Демо-шаблон статического сайта для кондитера, который продаёт через Telegram. Бренд `Madeleine` — пример; все тексты, контакты, товары и цвета меняются в одном файле `config.js`.

## Превью

https://coderrrcoffee.github.io/sweet-order-template/

## Что умеет

- витрина с категориями и корзиной;
- расчёт суммы и общего веса;
- форма: имя, телефон, дата, интервал, доставка/самовывоз, адрес, повод, надпись, комментарий;
- генерация готового текста заказа и открытие чата Telegram с этим текстом;
- копирование текста, если Telegram не подставил его автоматически;
- мобильная версия с липкой кнопкой;
- страница политики конфиденциальности;
- конфиг под нового клиента и сборка `node build.mjs`.

## Деплой на Vercel

1. Add New Project → Import Git Repository.
2. Framework Preset: **Other**.
3. Build Command: оставить пустым.
4. Output Directory: `.`.
5. Deploy.

## Как адаптировать

1. Откройте `config.js`.
2. Замените `brand`, `contacts`, `telegram` на данные клиента.
3. Замените `products` и фото в `assets/photos/`.
4. Подтвердите цены, веса и интервалы доставки.
5. Впишите домен в `meta.siteUrl`.

Демо-контакты `@madeleine_demo` и телефон `+7 999 000-00-00` — заглушки. Перед публикацией их обязательно заменить.

## Важно

Шаблон не содержит онлайн-оплаты, CRM и учёта остатков: заказ уходит в Telegram. Это осознанное решение, а не недоделка.
